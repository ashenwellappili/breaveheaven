# Brew Heaven ☕

A premium, modern web application for a specialty coffee sanctuary located on Marine Drive, Colombo 4. Built with dynamic interactive features, an ethical design, and a fully featured front-end shopping/checkout experience.

## Features 🌟

- **Artisanal Menu**: Browse classic espressos, specialty teas, cold brews, and fresh pastries.
- **Dynamic Shopping Cart**: Manage products in real-time with responsive counters and immediate total calculations.
- **Interactive Payment Portal**: Secure-styled checkout window simulating card input validation, load states, and credit card processing animations.
- **Detailed Success Receipt**: Custom-generated order ID references, item summary details, and pick-up guidance.
- **Staff Back-Office Portal**: Simulated staff operations dashboard for inventory, stock control, and low stock warnings.
- **Modern Typography & Styling**: Uses HSL color systems, custom TailindCSS palettes, smooth animations, and clean responsive interfaces.

## Local Setup 🚀

To run this application locally:

1. Clone or download this project directory:
   ```bash
   git clone https://github.com/your-username/brew-heaven.git
   ```
2. Open the directory containing the project:
   ```bash
   cd "brew-heaven/frontend"
   ```
3. Open `index.html` in your favorite web browser, or launch a local live-reload server:
   ```bash
   npx serve .
   ```

## Technologies Used 🛠️

- **HTML5** & semantic formatting
- **JavaScript** (ES6+) for interactive cart & payment simulations
- **Vanilla CSS** & **TailwindCSS** (via CDN) for modern, responsive responsive grid systems
- **Google Fonts** (Plus Jakarta Sans & Source Serif 4)
- **Material Symbols Outlined** icons
